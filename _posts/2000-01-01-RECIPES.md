### 食谱


| 菜品 | 分类 | 食材清单 | 烹饪流程 |
| ----------- | ----------- | ----------- | ----------- |
| 三蛋蒸肉饼 | 快手菜 | 1盒肉末<br>1颗皮蛋<br>1颗咸蛋黄<br>1勺酱油<br>适量盐<br>小半勺白胡椒 | 所有食材用手抓匀揉成肉饼，在肉饼中间打一颗鸡蛋，上汽蒸15min |
| 水汆蛋 | 快手菜 | 2颗鸡蛋<br>1份肉末<br>2把葱<br>适量盐和白胡椒 | 锅里加少量油，大火把油烧热，打入两个鸡蛋炒散<br>蛋液凝固成蛋片后下肉末翻炒到变色，加入一碗热水<br>撒适量盐和白胡椒调味，水开后继续煮1min，加入两把葱<br>或水开后加入方便面料包和面饼 |
| 腊味焖饭 | 快手菜 | 腊肠和腊肉<br>鸡蛋<br>生抽/老抽/糖<br>葱花 | 正常煮饭，米上面放腊肠和腊肉，打入鸡蛋（或在电饭煲冒烟之后打入）<br>4勺生抽+1勺老抽+2勺糖，饭煮完之后倒入电饭煲，撒上葱花搅拌 |
| 盐酒蒸鸡 | 快手菜 | 清远鸡/文昌鸡<br>盐<br>花雕酒/米酒/白酒<br>虫草花 | 清远鸡或文昌鸡切块，3勺盐（浓度5%）+1杯酒（花雕酒/米酒/白酒）泡1h<br>取出装盘撒上虫草花，上汽蒸10-20min |
| 大乱炖 | 快手菜 | 大土豆<br>鸡翅，茄子，豆角，大辣椒等<br>1大勺黄豆酱、甜面酱、豆瓣酱、酱油、糖<br>1颗八角 | 大土豆切块（小土豆可以不切）<br>起锅烧宽油，大火煎鸡翅，土豆，茄子，豆角，大辣椒等<br>加入所有调料翻炒均匀至蔬菜变软，加水没过食材炖30min<br>叶菜类出锅前5min加入 |
| 溏心蛋 | 快手菜 | 1颗鸡蛋 | 从冰箱内取出蛋，冷水下锅，中大火，水沸3min后关火即流心溏心蛋<br>关火后焖5min，即半熟蛋 |
| 番茄肉酱面 | 快手菜 |  | 番茄去皮切丁，2勺生抽+0.5勺老抽+1勺蚝油+1勺番茄酱+少许盐+0.5勺糖+1勺淀粉+半碗清水<br>油热加入葱蒜炒香，加入猪肉末（可加一点洋葱）炒至变色后加入番茄丁炒出汁<br>倒入料汁煮至浓稠<br>与此同时下面条煮熟捞出沥干，加入煮好的肉酱撒上葱花 |
| 芒果慕斯蛋糕 | 甜点 |  | 饼干碎80g+融化黄油35g翻拌均匀，倒入6寸模具压紧实，冷藏备用<br>芒果果肉350g打成泥<br>淡奶油200g+细砂糖35g，打发至酸奶状<br>吉利丁15g提前泡软，和温热牛奶50g搅拌融化倒入淡奶油中，再加入300g芒果泥搅拌均匀倒一半面糊到模具中，加入芒果果肉，再倒出剩余的面糊，冷冻40min<br>剩余芒果泥50g+水50g+吉利丁5g隔热水搅拌融化，倒入模具冷藏4h以上<br>用热风吹一吹模具四周，脱模，蓝莓芒果薄荷叶装饰 |
| 巴斯克蛋糕 | 甜点 |  | 奶油奶酪250g+淡奶油150g+2颗鸡蛋+1颗蛋黄+玉米淀粉20g+糖50g+香草精5g，用搅拌机搅打20s<br>放入垫了油纸的碗里，放入烤箱220度烤20min<br>放冰箱冷藏一晚 |
| 免烤蓝莓芝士蛋糕 | 甜点 |  | 水+现挤半个柠檬汁+20g白糖+2勺玉米淀粉煮至粘稠放入蓝莓250g<br>慢慢搅拌至成为蓝莓果酱，可加入50g树莓增加风味，小火慢煮<br>250g饼干碾碎+糖+融化的黄油搅拌均匀，倒入模具压紧实，冷藏30min<br>1kg奶油奶酪室温内放软，稍微搅拌后加入200g糖霜继续搅拌<br>加入30ml酸奶油和半个柠檬汁搅拌均匀，打发至酸奶状<br>150ml淡奶油打发为奶油状，加入奶油奶酪中，以画圈再从中间划开的方式搅拌，至细腻丝滑浓稠即可<br>取出蛋糕底，一层奶油一层果酱，封上保鲜膜冷藏过夜，脱模水果装饰 |
| 蜜汁手枪腿 | 微波炉料理 |  | 手枪鸡腿改花刀，1勺奥尔良粉+1-2勺蜂蜜+1勺蚝油+0.5勺老抽+3勺清水+葱姜，抓匀后鸡皮朝下腌制30min<br>挑出葱姜，盖上保鲜膜扎孔，高火（700w）5min<br>翻面，盖上新的保鲜膜扎孔，高火5min（如果水份不足可以再添加一点清水） |
| 黄焖鸡 | 微波炉料理 |  | 1勺黄豆酱+1.5勺生抽+1勺蚝油+适量白胡椒+0.5勺老抽+小半茶匙白糖与切块的鸡肉，香菇，土豆拌匀<br>加水至碗的一半满，盖上保鲜膜扎孔，高火6min<br>加入青椒后再高火2min<br>（土豆必须小块不然容易夹生） |
| 香菇鸡腿肉 | 微波炉料理 |  | 鸡腿肉剪小块，半茶匙白胡椒+1勺蚝油+2勺生抽+0.5勺老抽+0.5勺黄豆酱，姜片去腥，腌制15min<br>挑出姜片，剪入香菇拌匀，高火6min，撒葱花 |
| 柠檬鸡 | 微波炉料理 |  | 鸡腿肉3份，洋葱切条+1勺蚝油+2勺生抽，腌制7-8min，高火5min<br>加入去籽柠檬片和小米辣，高火2min，撒香菜 |
| 泰式酸辣汁 | 万能蘸汁 |  | 洋葱，小米椒，香菜根，薄荷，蒜头，线椒一起打碎，生抽鱼露芝麻油盐一勺，糖一勺半，青柠半个（汁），柠檬片两片，凉白开适量，搭配海鲜吃 |
| 白灼汁蘸水 | 万能蘸汁 |  | 沙姜，小米椒，香菜分开搅打，加入蒜末，青柠，四个青柠汁，蒸鱼豉油蚝油芝麻油糖一勺，山葵和适量凉白开 |
| 万能蒜蓉酱 | 万能蘸汁 |  | 打蒜末，泼热油，生抽蚝油盐糖一勺，搭配海鲜排骨鸡翅生蚝等 |

### 万能公式
凉拌料汁
（食材改刀打薄，主要目的是增大面积；肉类可用生姜片青红花椒和料酒汆水烫熟，放入冰水后沥干备用）
打底:盐🧂
提鲜:生抽，老抽，蚝油，鸡精，味精，糖
提味:酸辣分百香果+柠檬🍋，也可醋。辣用辣鲜露+油辣子，➕洋葱🧅，葱花，蒜末，香菜，
增香:葱头油
另一个是热油激发的方式:洋葱🧅，蒜末，藤椒，青花椒炒香。倒入料汁，加入香菜，蒜末，葱，藤椒油。

关键词：懒人、备餐、下饭、快手、空气炸锅、微波炉、免烤……

夏天不开火备餐快，冷便当冷泡茶

冷泡茶：恩施玉露、七窨茉莉花茶（栀子绿茶、姜花乌龙、珠兰花茶、桂花红茶）、东方美人、蒙顶甘露、烟熏小种、桃源小种）；碧螺春、都匀毛尖（芽头占比高的绿茶）、白牡丹、白毫银针、黄茶、铁观音、漳平水仙、凤凰单丛、台湾乌龙、中轻火的岩茶、祁门红茶
通用茶水比：1比150；但是宁可浓不可淡
时间：冰箱冷藏4-8小时
可添加应季水果：荔枝桃子葡萄柠檬/黄冰糖

小米+姜丝+红枣+空气炸锅150度25分钟（多次搅拌）=空气炸锅版姜米茶，用于冲饮

自制单人小火锅
魔芋丝，冻豆腐，汕头牛肉丸，午餐肉，肥牛片，绿叶菜，鸭血，土豆片以及其他食材
木薯粉水晶冻糕
椰汁芒果/百合桂花/菊蜜桂花/玫瑰桂花/水蜜桃桂花/椰汁红豆/西米椰汁/斑斓千层
果茶公式=茶汤（茉莉绿茶/栀子红茶/乌龙茶/幽兰铁观音）/【味全0蔗糖乳酸菌饮料】+浓缩果汁+小料（小包装免煮珍珠/芋圆/荔浦芋头）
乌冬面+杂粮饭+蛋+牛肉（其他高蛋白肉类亦可）
屈臣氏青柠汁浓浆

蔬菜买回来之后摘掉腐败部分，不洗不切
热带水果不放冰箱
黄瓜和西兰花零度保鲜，罗勒叶常温
喜水蔬菜（芹菜、西芹、香菜、罗勒、芦笋等）：用厨房纸吸干多余水分，浸湿贴紧蔬菜根部（反之则使用干厨房纸；绝大多数绿叶菜喜湿）最后保鲜膜包裹
豆类适合冷冻保存，使用时无需解冻
肉分小包装冷冻，在冷藏室解冻

中式凉拌菜：水晶脆粉皮，龙须菜，芋头粉段，素海蜇丝，黄瓜丝，胡萝卜丝，海带丝

酸辣汤底料：烧热约2-3勺食用油，趁热浇入蒜末1勺、葱花1勺、熟芝麻1勺和辣椒面1勺中去，加入生抽1-2勺、香醋2勺、花椒粉1小勺、白糖小半勺、盐少许、鸡精少许和芝麻酱1小勺，搅拌均匀；将煮粉条的滚烫高汤舀几勺冲入碗中，最后淋上香醋1勺

港式冻柠茶
红茶：沸水比例按1：30焖泡10分钟，捞出茶包倒入冰块，搅拌融化，一半冷冻一半冷藏；鲜柠檬片4片去籽，加入糖浆10ml（或其他甜味剂）挤压出汁，加入冰茶砖后倒入冰茶汤

凉拌酸辣汁：
直接将15g（1汤匙）白糖倒入干燥的350ml容器中。
依次加入100ml生抽、150ml香醋，盖上盖子摇晃几下，帮助白糖溶解。
打开盖子，再加入60ml（4汤匙）油泼辣子、10ml（2茶匙）花椒油、5ml（1茶匙）香油以及蒜汁等；盖上盖子，充分摇匀即可

溏心蛋
开水下锅3min
杀菌做法：洗净鸡蛋后在表面用针扎一个小孔，水开中火下锅，煮6min/6m30s/7min；剥壳时先过冰水，挤碎所有壳之后再放入冷水中剥壳
酱汁：500ml水中+200ml生抽/日式酱油+100ml味淋（九江双蒸酒+白糖可代替）+鲭鱼干*1（打碎）+1小把鲣鱼干+鳀鱼干若干（鱼干部分可用鱼露和鸡精/味精代替）+1小勺茴香+八角*1+香叶*1+对半切开的大蒜*2+姜片*1，小火煮沸2min后关火放凉进冰箱24hr；泡入鸡蛋（可以顶上放一张厨房纸保证上色均匀）继续进冰箱静置24hr

番茄肥牛浓汤面
番茄去皮，和白洋葱切丁；锅中倒水，料酒；肥牛灼水捞起待用；部分番茄丁加水打汁（也可以直接切碎一点炒出汁）放油爆炒白洋葱，加番茄丁炒均匀，加盖焖煮时煎一个荷包蛋；倒入番茄汁+热水+1勺生抽+0.5勺蚝油+0.5勺白糖；捞去浮沫加面饼，少许盐调味，放入肥牛与煎蛋撒葱花

鲜甜菌菇蔬菜汤
香菇干+茶树菇干+1.2L水煮开5min后关火备用；半个白洋葱+半个胡萝卜切丁+15ml橄榄油炒软，加1g盐炒出美拉德；加入双孢菇，炒出美拉德 （加入煎豆腐，可选）；加西红柿+1g盐+1g白胡椒+1g黑胡椒，小火炒出汁水，炒软；加入刚才煮菌菇干的水，和菌菇煮5min；加入芦笋段（4根）和羽衣甘蓝，煮1-2min，出锅

白菜酿肉卷
搅打猪肉末，胡萝卜+泡发好的冬菇打碎备用；加入生抽1勺+蚝油1勺+老抽0.5勺+料酒1勺+盐+胡椒+淀粉+葱末腌制0.5小时；加入胡萝卜和冬菇丁；白菜煮软捞出，加入准备好的肉末卷起来上锅蒸20分钟；生抽1勺+老抽0.5勺+蚝油1勺+淀粉1勺+白糖0.5勺调成料汁；热油爆香蒜末和辣椒碎，倒入酱汁煮至浓稠淋到白菜酿肉卷上，撒上葱花

孜然烤花菜
花菜洗净放入保鲜袋，1勺辣椒面+适量盐+2圈橄榄油+1勺生抽+1勺孜然粉+适量黑胡椒30s摇匀；平整放入锡纸盘，空气炸锅180度10分钟（中途需翻面）

蓝莓山药
1盒蓝莓+0卡糖（或白糖）入空气炸锅180度10min，加入柠檬汁压碎后再烤5min，少许温水稀释做成果酱；300g山药入蒸锅上汽蒸熟捣烂，加一点牛奶和白糖，做个造型淋上蓝莓酱

茄子煲
茄子切片，加入少许食盐腌制10min出水分；切碎适量葱蒜小米辣；酱油+少许白糖+淀粉+清水拌匀备用；腌制好的茄子挤干水分，加入淀粉抓拌均匀，宽油160-170度下锅油炸至微微金黄色（也可以蒸10-15min代替油炸）；爆香葱蒜辣椒，放豆瓣酱炒出红油，再放茄子翻炒；砂锅底部铺上金针菇，放入茄子和酱汁焖煮（也可以加入粉丝）最后撒入少许葱花

沙茶肥牛粉丝煲

椒麻西兰花
西兰花分批放入沸水中焯水，待水再次沸腾后立即捞出，放在一个大平底容器中，便于搅拌和吸汁。加入藤椒油3茶匙，蒸鱼豉油3茶匙，静置两分钟。

柠檬蜜
直接一层冰糖可以溜缝儿放 一层柠檬片（去籽）放冰箱两三天就能喝
