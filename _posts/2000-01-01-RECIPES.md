| 大乱炖 | 快手菜 | 大土豆<br>鸡翅，茄子，豆角，大辣椒等<br>1大勺黄豆酱、甜面酱、豆瓣酱、酱油、糖<br>1颗八角 | 大土豆切块（小土豆可以不切）<br>起锅烧宽油，大火煎鸡翅，土豆，茄子，豆角，大辣椒等<br>加入所有调料翻炒均匀至蔬菜变软，加水没过食材炖30min<br>叶菜类出锅前5min加入 |

| 番茄肉酱面 | 快手菜 |  | 番茄去皮切丁，2勺生抽+0.5勺老抽+1勺蚝油+1勺番茄酱+少许盐+0.5勺糖+1勺淀粉+半碗清水<br>油热加入葱蒜炒香，加入猪肉末（可加一点洋葱）炒至变色后加入番茄丁炒出汁<br>倒入料汁煮至浓稠<br>与此同时下面条煮熟捞出沥干，加入煮好的肉酱撒上葱花 |
| 芒果慕斯蛋糕 | 甜点 |  | 饼干碎80g+融化黄油35g翻拌均匀，倒入6寸模具压紧实，冷藏备用<br>芒果果肉350g打成泥<br>淡奶油200g+细砂糖35g，打发至酸奶状<br>吉利丁15g提前泡软，和温热牛奶50g搅拌融化倒入淡奶油中，再加入300g芒果泥搅拌均匀倒一半面糊到模具中，加入芒果果肉，再倒出剩余的面糊，冷冻40min<br>剩余芒果泥50g+水50g+吉利丁5g隔热水搅拌融化，倒入模具冷藏4h以上<br>用热风吹一吹模具四周，脱模，蓝莓芒果薄荷叶装饰 |
| 巴斯克蛋糕 | 甜点 |  | 奶油奶酪250g+淡奶油150g+2颗鸡蛋+1颗蛋黄+玉米淀粉20g+糖50g+香草精5g，用搅拌机搅打20s<br>放入垫了油纸的碗里，放入烤箱220度烤20min<br>放冰箱冷藏一晚 |
| 免烤蓝莓芝士蛋糕 | 甜点 |  | 水+现挤半个柠檬汁+20g白糖+2勺玉米淀粉煮至粘稠放入蓝莓250g<br>慢慢搅拌至成为蓝莓果酱，可加入50g树莓增加风味，小火慢煮<br>250g饼干碾碎+糖+融化的黄油搅拌均匀，倒入模具压紧实，冷藏30min<br>1kg奶油奶酪室温内放软，稍微搅拌后加入200g糖霜继续搅拌<br>加入30ml酸奶油和半个柠檬汁搅拌均匀，打发至酸奶状<br>150ml淡奶油打发为奶油状，加入奶油奶酪中，以画圈再从中间划开的方式搅拌，至细腻丝滑浓稠即可<br>取出蛋糕底，一层奶油一层果酱，封上保鲜膜冷藏过夜，脱模水果装饰 |
| 蜜汁手枪腿 | 微波炉料理 |  | 手枪鸡腿改花刀，1勺奥尔良粉+1-2勺蜂蜜+1勺蚝油+0.5勺老抽+3勺清水+葱姜，抓匀后鸡皮朝下腌制30min<br>挑出葱姜，盖上保鲜膜扎孔，高火（700w）5min<br>翻面，盖上新的保鲜膜扎孔，高火5min（如果水份不足可以再添加一点清水） |
| 黄焖鸡 | 微波炉料理 |  | 1勺黄豆酱+1.5勺生抽+1勺蚝油+适量白胡椒+0.5勺老抽+小半茶匙白糖与切块的鸡肉，香菇，土豆拌匀<br>加水至碗的一半满，盖上保鲜膜扎孔，高火6min<br>加入青椒后再高火2min<br>（土豆必须小块不然容易夹生） |
